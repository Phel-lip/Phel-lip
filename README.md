# 🚀 Projeto principal — DailyXP Core

Aplicação Full Stack de gerenciamento de hábitos, com sistema de recompensas por XP, CRUD completo e persistência de dados em PostgreSQL.

<p align="center">
  <a href="https://phel-lip.github.io/dailyxp-core/">
    <img src="https://raw.githubusercontent.com/Phel-lip/dailyxp-core/main/dailyxp.png" alt="DailyXP Core - Prévia da aplicação" width="85%" />
  </a>
</p>

### Funcionalidades

- Cadastro, listagem e exclusão de hábitos.
- Conclusão e reabertura de atividades.
- Sistema de pontuação com XP.
- Persistência em banco de dados PostgreSQL.
- Separação de hábitos por identificador anônimo do navegador.
- Interface responsiva para desktop e mobile.

### Arquitetura e tecnologias

- **Front-End:** React + Vite.
- **Back-End:** C# / ASP.NET Core (.NET 10).
- **API:** REST com Minimal APIs.
- **Banco de dados:** PostgreSQL (Neon).
- **Acesso ao banco:** Npgsql, sem Entity Framework.
- **Deploy:** GitHub Pages + Render com Docker.
